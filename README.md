# Frontend

Interfaz del calendario de adviento: lo que ella ve y con lo que interactúa.

Muestra la cuadrícula de días del 1 al 25 de diciembre y el apartado especial del 26 (su cumpleaños), la cuenta regresiva antes de que empiece, y la animación de abrir cada sorpresa.

No decide qué días están desbloqueados ni guarda el contenido de las sorpresas: todo eso se lo pide al backend.

Hecho con React, TypeScript y Vite.

## Comandos

```bash
pnpm install   # instalar dependencias
pnpm dev       # servidor de desarrollo
pnpm build     # compilar para producción
pnpm lint      # revisar el código
```
